# manualesCuaDriver

Proyecto basado en [CUA](https://github.com/trycua/cua) para crear manuales de usuario de aplicaciones a partir de su exploración verificada con `cua-driver`.

## Contenido

- [`SKILL.md`](./SKILL.md): flujo y criterios para preparar manuales en Markdown y, tras su aprobación, generar su versión HTML.
- [`ManualCalculadora/`](./ManualCalculadora/): ejemplo de manual de la función suma en GNOME Calculator, en Markdown y HTML, con capturas.
- [`pptx/Cua Spaces y Cua Driver.pdf`](./pptx/Cua%20Spaces%20y%20Cua%20Driver.pdf): material de referencia sobre CUA Spaces y CUA Driver.

## Modelo utilizado

**qwen/qwen3.6-35b-a3b**
